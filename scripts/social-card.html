git-rescue

Messed up git?
Get your work back.

Says what went wrong in plain words, with the exact commands that fix it. Backs up first. Finds staged files lost to reset --hard.

$ npx github:zch6a/git-rescue
$ git reset --hard HEAD~2 # oops $ git-rescue ! 1. 2 commits fell off main with a reset d1cdd9d3 parser handles escapes 3418468f parser handles quotes a) Keep them on a new branch [safe] b) Put main back where it was [careful] · 2. 1 file you staged but never committed 169672f8 TODO: call the bank about… $ git-rescue fix 1a --yes ✓ git branch rescued/main-before-reset-d1cdd9d3
